## 무엇이 다른가요?
1. 커스텀 해상도 관리
2. 앱 이탈 후 복귀 시 자동 세션 재진입
3. 가상 패드 옵션 다양화
4. 트랙패드 관성 ON/OFF, 감도 설정 추가
5. 레터박스 BOTTOM 옵션 추가
6. 자동회전 지원. **권장 호스트 웹앱에서 회전하려는 해상도 수동 입력 필요**
7. 폴드형 폼팩터에서도 네이티브 해상도 적용
8. 클라이언트 해상도 변경시 호스트 해상도 자동 변경. **권장 호스트 웹앱에서 변경하려는 해상도 수동 입력 필요**
9. 듀얼 스크린 디바이스에서 가상 게임패드를 양 디스플레이에 띄우기
